# 🎮 Reboot - 게임 강의 매칭 플랫폼

> **게임 전문가의 강의를 원하는 유저를 매칭해주는 서비스**  
> 사용자 맞춤 강의 추천부터 예약, 결제, 영상 스트리밍까지 제공하는 통합 플랫폼입니다.
> 이 프로젝트는 팀 프로젝트로 시작되었으며, 이후 개인적으로 기능 및 구조를 리팩터링하여 개선한 버전입니다.

---

## 📌 프로젝트 개요

- **프로젝트명**: Reboot
- **목적**: "맞춤 게임 강의를 찾기 어려운 유저"와 "전문성을 가진 강사"를 연결하기 위한 플랫폼입니다.
- **유형**: 팀 프로젝트 → 개인 리팩토링 (Fork 관계 제거 후 독립 저장소로 운영)
- **개발 기간**: 팀 (2025.04.28 ~ 2025.05.14) / 개인 리팩토링 (2025.05 ~ )
- **담당 역할**: 강의 예약 기능, 결제 시스템 (TossPay 연동)
- **개선 포인트**: 결제 안정성, 예약 중복 방지, 예외 처리 개선, Swagger 문서화

---


## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🔐 로그인 / 회원가입 | JWT 기반 자체 로그인, OAuth2 소셜 로그인 (Google,Kakao,Naver) |
| 🤖 맞춤 강의 추천 | Together.ai 기반 맞춤형 강의 추천 |
| 📅 강의 예약 기능 | 날짜 기반 강의 예약 |
| 💳 결제 시스템 | Toss Pay API 연동 |
| 🧾 마이페이지 | 회원정보 수정, 수강 내역 조회 등 |
| 🎥 객체스토리지 | Supabase Storage를 통한 피드백 요청 영상 업로드 |

## 🙋🏻 담당 파트 (기여 내용)

### ✅ 강의 예약 기능 구현
- 예약 생성/조회/수정/삭제 (CRUD) API 구현
- 예약 시간 검증 로직은 미포함 (향후 개선 예정)
- 사용자 마이페이지 내 예약 조회 기능과 연동

### ✅ 결제 시스템 (TossPay 연동)
- 결제 및 환불 시 API 요청
- 리디렉션 기반 결제 완료 처리 (Webhook 미사용)

### 배포
- rencher를 통한 docker 기반 배포

## 🛠️ 개선 사항 요약 (`refactor/main` 브랜치 기준)

| 개선 항목 | 설명 |
|-----------|------|
| 예약 중복 방지 | 기존 단순 예약 insert → 예약 가능 여부 사전 검증 로직 추가 |
| 결제 redirect 안정화 | Toss 결제 후 success/fail redirect 분기처리 명확화 |
| 전역 예외 처리 | ControllerAdvice 도입으로 예외 통일, 사용자 메시지 정리 |
| Swagger 문서화 보완 | 예약 및 결제 요청/응답 명세와 예시 추가 |
| 테스트 코드 도입 | 예약/결제 로직 중심의 단위 테스트 작성 (JUnit) |
| 커밋 컨벤션 정비 | 개선 이후 커밋부터는 일관된 메시지 관리 (`refactor`, `fix`, `feat`) |

> 커밋 히스토리로 개선 과정을 확인하실 수 있습니다.
